# 遗迹守卫设施图集

`facilities.png`：2026-10-19 通过内置 image_gen 生成的原创透明 RGBA 图集，1536×1024。生成参考是本工程已有 `art/western/props.png`，以匹配石材、金属、宝石、照明与三分之四俯视角。保留原始生成像素和透明通道，没有以脚本抠图、描摹或重画位图。

生成要求：4列×3行，十二种独立设施；绘制精细的西方奇幻石材、黄铜与银质构件，东方飞剑作为魔法设施的一种。依次为飞剑法阵、符文弩塔、炼金炮台、雷鸣尖塔、龙息喷口、寒霜碑、引力符井、守护石像、荆棘地阵、治愈圣泉、共鸣水晶、灵能采集器。每个设施独立、完整、四周留空，透明背景，无文字、标签、数字、网格、水印或烟雾。古式符文机械，不使用现代科技外形。

原始生成文件标识：`exec-a182a851-1be9-42e1-b019-fc5e4aa7357f.png`。

运行时 UV 区域由 `scripts/td/catalog.gd` 的 `REGIONS` 明确记录；图集行距并不完全均匀，因此不用简单等分，避免上一行底座出现在下一座设施上。每种设施有一套原画，四级以底座光点、最高级符文及实际攻击逻辑区分，**不是48套独立建模或逐帧动画**。

飞剑、箭矢、炼金弹和魔法光晕复用工程已有资产与其来源说明。本批没有新增第三方下载素材。
