# 0.8.0「灵境重铸」更新日志

## 玩家可见变化

- 三职业在八相位步态基础上补充起步、急停、转身、闪避、受击、换弹、技能、终极技能、组合技、胜利与倒地形变。
- 剑修普攻向前压势，火枪手体现后坐回弹，游侠体现拉弓释力；武器出手点继续跟随角色与武器一体帧。
- 三个 C 技能加入职业专属的聚势、持续、命中、终结和残留材质层，并控制高密度对象预算。
- 组合技 HUD 会显示教学步骤、就绪名称、按键链和剩余时间；核心印记窗口约 10 秒，触发后显示中央横幅并写入战报计数。
- 深渊 Buff 在 3 / 5 / 10 / 20 层形成四次质变，20 层后每 10 层循环突破；奖励卡和属性页显示下一节点。
- 普攻和技能加入短输入缓冲，闪避可以取消收势和换弹；取消换弹不会补充弹药。
- 游戏窗口、主菜单和页面标题统一为“第八版 · 灵境重铸”。

## 沿用并重新验证

- 三职业九套流派、36 条互斥技能进化路线。
- 四种战术普通怪、六种精英词缀和三种房间目标。
- 第二章分支地图、事件、隐藏房和路线信息。
- 装备强化、九种流派装备机制、章节软保底和首领定向掉落。
- 图鉴分类、属性与 Buff、天赋滚动位置、详细战报、六章、噜噜 Boss 和无尽深渊。
- 旧存档增量兼容、1920×1080 内部坐标和四档 16:9 窗口分辨率。

本版没有加入来源不明的外部素材。新增画面由工程已有许可资源、代码绘制材质层和程序动作形变组成。
