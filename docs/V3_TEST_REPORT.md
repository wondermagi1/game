# 三途试炼 V0.3.0 验证报告

日期：2026-09-22；Godot 4.7.2.stable；Windows，GL Compatibility。测试使用内存档或 res://tests 下隔离文件，不读写真实玩家 profile。

## 功能检查

- regression_v3.gd：371 项通过，无失败。覆盖强化、改键、滚动、六组合、12 技能×5 等级节点、无限叠层、数值限制、30 层推进与检查点等。
- compatibility_v3.gd：467 项通过，无失败。继承旧功能检查并更新 60/10 级预期：背包、套装、掉落抽样、保底、交易、道具、暂停、回合、隐藏路线与存档等。
- integration_v3.gd：21 项通过，无失败。真实 InputEvent 使用药剂、改键时隔离输入、检查点实际写盘/重载、64 位 RNG 与商品已售状态恢复，以及三档完整构筑固定目标输出。

## 图形与性能

RTX 4060 Laptop GPU，1280×720窗口，1920×1080逻辑视口，真实 OpenGL 渲染。压力样本：32敌人，450弹体，适用 Buff 各100层，四技能10级，周期性组合爆发；预热180帧后采样300帧。平均 12.89 ms（77.6 FPS），P95 15.37 ms。这是本机短时样本，不能推广为所有设备保证。

实际渲染检查菜单、六章、装备、天赋、图鉴、按键、设置、战斗、Buff、奖励、整备、商店、结果、深渊整备与续存入口，共16张截图。界面列表可滚动；危险描边位于玩家特效上方。

## 已知限制与未验证项

- 程序化敌人及合成音仍属于开发美术。角色沿用第二版 2D 图集，没有制作3D模型、完整骨骼或逐帧动作。
- 已实际渲染特效并验证音效调用/音量控制；没有完成专业试听混音或真实用户长时间手感评测。
- Buff 使用三类共享进阶机制及个别专属机制；尚未为36种Buff逐个制作独立美术资产。
- 只支持安全整备点继续深渊，不支持战斗现场恢复。没有模拟突然断电、磁盘物理故障或双进程并发存档。
- 自动化日志中 Windows 根证书读取、受限目录下 shader/editor 设置写入警告属于执行环境限制；发布检查应另行确认没有 GDScript 编译或运行错误。
- 旧 V1/V2 测试与报告作为历史记录保留；本版判定以 tests/*v3* 与本报告为准。

## 复现命令

在工程目录用 Godot 命令行：

```powershell
Godot.exe --headless --fixed-fps 60 --path . --script res://tests/regression_v3.gd --log-file test-v3.log
Godot.exe --headless --fixed-fps 60 --path . --script res://tests/compatibility_v3.gd --log-file test-compat.log
Godot.exe --headless --fixed-fps 60 --path . --script res://tests/integration_v3.gd --log-file test-integration.log
Godot.exe --headless --fixed-fps 60 --disable-render-loop --path . --script res://tests/autoplay_v3.gd --log-file autoplay.log -- --chapter=6
Godot.exe --headless --fixed-fps 60 --disable-render-loop --path . --script res://tests/abyss_combat_v3.gd --log-file abyss.log -- --build=developed
Godot.exe --path . --script res://tests/capture_v3.gd --log-file capture.log
Godot.exe --path . --script res://tests/stress_v3.gd --log-file stress.log
```

不要只看进程退出码：Godot 的某些脚本错误可能仍返回0，应检查日志和 JSON failures。
