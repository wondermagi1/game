## 数值口径

常规攻击：(基础攻击 + 等级/装备固定值 + 本局固定值) × (1 + 永久百分比 + 本局百分比)。深渊再乘以 (1 + 进阶/超额攻击系数)。暴击、首发、距离、组合和技能倍率在命中链中分别处理。

普通模式防御上限 80；承伤 = 原伤 × 100/(100+防御)。深渊防御为 400x/(400+x)，冷却缩减为 0.8x/(0.8+x)，均逐渐接近上限。更多边界值见 ABYSS_AND_BUFFS.md。

角色获得每级 1 天赋点，60 级共 59 点。技能 2–10 级所需角色等级依次为 10/20/25/30/35/40/45/50/60，花费 2/3/3/3/4/4/4/5/5 点。单技能点满需 33 点。六个被动各最多 3 点，不能全部点满。

经验：1–30 级保留旧公式 60+15(L−1)+3(L−1)²；31 级起每级需求 3018+95(L−30)+2(L−30)²。深渊参考构筑 20 分钟约由 Lv.30 达到 Lv.35–37；高养成 30 层记录约 Lv.45→50，详见实测文件，不代表所有玩家升级速度。

装备强化成本：金币 30+15×目标等级²；材料 1+floor(目标等级/3)。强化只放大基础属性，每级 +3%，不重掷词条。

可直接查看 docs/catalog_v3.json 的实际配置快照。更改稳定 ID、职业序号、装备部位前需补迁移；仅修改显示文案不会更改装备 UID。
