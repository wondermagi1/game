# 无尽深渊与 Buff 规则

## 层流程

第六章通关后开放。每层一波；普通层持续增援 22+min(18,层数×0.35) 秒，结束后清完剩余敌人即可奖励。每层三选一，5 的倍数有精英与整备；10 的倍数替换为轮换首领。每五层随机给予一个技能本局等级 +1，有效最高 10 级。

整备点可换装、强化、分配天赋、固定库存购买、配置道具、查看图鉴，并保存退出。继续下一层恢复 25% 生命。深渊不会每层重置不屈；一次深渊仅能抵挡一次致命伤。常规章节仍按回合计算不屈。

三角色分别保存历史最高完成层数。金币/经验/装备/材料属于永久收益，Buff、临时技能、检查点生命和战斗状态属于本次深渊。

## 固定难度

怪物取第六章基础值，再乘层数系数：生命 = 0.6+0.065F+0.0025F^1.7；伤害 = 0.7+0.025F+0.0004F^1.5。不读取玩家实时 DPS、装备或天赋进行补偿。后期靠成长、控制和躲避应对，不无限增加同屏敌人。

初始 1–10 层面向已通主线构筑；11–30 层要求逐渐形成装备/天赋/Buff 配合。更高层无关卡终点，但当前主要完成前 30 层战斗与高层数值/性能测试，不能据此声称所有高层已平衡。

## 36 种 Buff

主线沿用 data.gd 的有限层数；深渊保留无限累计计数。每个 Buff 在 5、10、20、40 层均给 +10% 进阶攻击，并解锁或提高对应机制。每一机制家族采用当前最高进阶，避免每个 Buff 单独产生额外实体。

| 家族 | 对应属性 | 四阶机制 |
| --- | --- | --- |
| 守护 | 生命、防御、盾、复活、治疗与恢复 | 每 8 秒给予最大生命 3/6/9/12% 护盾，持续 4 秒；取较大护盾，不无限相加 |
| 疾行 | 移速、击杀移速、闪避冷却、拾取 | 闪避追加半径 100/140/180/220 冲击，造成 40/80/120/160% 攻击 |
| 共鸣 | 其余输出、机制属性 | 每 3 秒发射 2/3/4/5 道职业弹，伤害 35/70/105/140%，穿透 1/2/3/4 目标 |

燃烧额外层提高持续伤害，5 层后直接击杀燃烧目标会爆破，1 秒间隔且不递归。静心层数缩短重新形成护盾所需无伤时间，最低 2.5 秒，5 层解锁抵伤反击。不屈额外层增加复活回复比例，最高 60%，不会增加无限复活次数。这些布尔 Buff 的额外层也转化攻击，不成为无效选项。

## 数量、概率与工程预算

| 项目 | 有效限制与溢出 |
| --- | --- |
| 额外多重弹 | 最多 +6，超额每单位转攻击 +6% |
| 穿透 / 弹射 | Buff 部分最多 +8 / +6，超额每单位转攻击 +6% |
| 弹匣 | 总容量 30，超额每单位转攻击 +6% |
| 爆破半径 Buff / 拾取半径 Buff | 最多 +300 / +900，超额每单位转攻击 +0.2% |
| 剑阵 Buff / 弹速百分比 / 击杀移速 / 击杀攻速 | +8 / +200% / +60% / +200%，超额每单位转攻击 +6% |
| 暴击率 | 80%，超额百分点转换为攻击百分比 |
| 攻击频率 | 12.5 次/秒，超额每 1 次/秒转攻击 +5% |
| 常驻移速 | 650，超额每像素/秒转攻击 +0.05% |
| 冷却 / 换弹 / 防御 | 使用渐近软上限；冷却极限 80%，防御渐近 400 |
| 布尔效果 | 首层生效，额外层每层攻击 +6% |
| 数值保护 | 属性计算最多 1e15，原始 Buff 分量最多 1e12，避免浮点失控；这是工程安全范围，不是 UI 层数限制 |

最多 32 敌人、450 弹体、40 区域、240 粒子、80 环、350 拖尾、30 法阵、80 浮字。低特效档降低后三类的密度。实体饱和时同来源友方弹的额外输出合并到现有弹体，不再制造无限对象；敌方过量子弹丢弃以保留性能，不转为不公平的额外伤害。伤害数字超过十亿以 M 缩写。

复活、护盾、内置触发间隔等存在设计限制；无限层数不表示无限次数、100% 减伤或零冷却。所有上限在实现与本说明中公开。
