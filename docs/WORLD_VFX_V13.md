## 危险信息与玩法边界

- “大范围、高速度”本批作用于视觉扩散、冲锋拖尾和技能层次，**没有扩大伤害半径、提高敌方弹速、缩短前摇或增加敌人数**。伤害与可躲避时间沿用现有数值。
- 危险轮廓仍显示在角色特效上方（z=80），纹理不代替精确范围边界。地面圆形预警保留边缘和倒计时弧，防止华丽素材遮盖危险信息。
- 修复原来铁甲统领、试炼守卫每次蓄力都会画冲锋红线的问题。现在只对实际冲锋招式显示通道；长度来自既有速度×时长（384、481、281.2 像素），宽度对应现有近身接触阈值。障碍物仍由原物理碰撞中止冲锋，预警表示无遮挡情况下的最大路径。
- 已获玩家认可的火枪圆弹、暖金辉光、旧版火枪爆炸火星与声音保留。通用光圈升级不再因当前玩家选择火枪而误回退所有敌人和道具的表现。
- 冰霜道具仍作用于全部敌人；首次晶体爆发只为最多八只敌人生成装饰事件，其余敌人的持续减速材质照常显示。

## 资源与实现

- `scripts/world_effect_art.gd` 仅做显示，使用现有 `skill_textures.gd` 的缓存图片和四边形，不产生伤害、碰撞或战斗随机数。
- 继续复用现有 Kenney 的 CC0 烟雾、火焰、柔光，以及 Cethiel 的 CC0 奥术序列。旧许可与选择记录在 `docs/SKILL_VFX_V12.md` 与 `art/v12/sources`。
- 新增 `art/v13/aether-vortex.png`、`crystal-barrier.png`、`lightning-bolt.png`：由内置 **image_gen** 生成的透明 PNG，不宣称为开源下载素材或真实 3D 模型。原像素保留，完整提示词与原始文件名记录于 `prompts.json`、`lightning-prompt.json`。
- Godot 导入为带 mipmap 的 512 像素旋涡/护盾、768 像素落雷。原始 PNG 自带 Alpha，不通过黑底混合掩盖背景。
- 短时事件列表按低/中/高档采用 12/22/32 的新增预算；冲锋拖尾低档每 0.14 秒、高档每 0.08 秒生成一次。无逐粒子节点、无逐发动态光源；质量降低会减少层数和光点。
- 动画时间由战斗寿命/阶段进度驱动；暂停时停止推进。减少动态效果时去掉旋涡旋转、持续护盾高光绕转和粒子漂移，但保留必要的施法展开、消退和伤害预警。
- 换房、清理攻击与退出时清空新事件；Boss 转阶段/死亡清除敌方攻击表现。现有角色、技能逻辑和存档结构不变。

已确认三张图有 Alpha 通道并可导入；Godot 4.7.2 `--check-only --script scripts/game.gd` 通过，未报告脚本解析错误。资源导入进程退出码为 0；隔离环境仍出现既有编辑器设置 `Safe save failed` 提示，未禁用系统防护或安全保存。新资源生成了导入缓存。
