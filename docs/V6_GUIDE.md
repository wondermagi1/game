# 第六版实现、资源和验收边界

> 以下记录 0.6.0 的实现。火枪手表现与游侠音效已在 0.6.1 按反馈回退，当前行为以 [0.6.1 说明](V061_FEEDBACK.md) 为准。

## 采用的角色路线

用户明确要求效果优先，分层效果不如 2.0/3.0 时将人物和武器放在一起制作。因此先前的 2D 关节拆件原型未作为最终默认路线：它的腿部和背向持械不足以达到目标。默认路线是 `actor_visual → actor_integrated → actor_v6 → actor_v5`，普通怪物继续沿用已有可爱贴图。

`art/v6/*-integrated.png` 为三张原始透明图集，每张 32 个完整人物+武器姿势。上两行不是独立骨骼组件。四组分别是持械、左右脚移动接触、释放动作。镜像没有算作额外动作，原图像素保持原样。

生成图集不是精确均匀网格。`integrated_regions.json` 保存完整连通主体的区域、脚底锚点及绘制边界；运行时缓存纹理网格隔开相邻图块，避免裁出悬浮的枪头/弓梢。`tools/analyze_atlas_v6.py` 只分析元数据，不修改 PNG。原始拆件图、`rig_regions.json`、`pose_library.gd` 留作实验源，可在角色 Inspector 打开 articulated_preview 对比；没有将其中 25 个程序状态宣称为 25 套完整手绘动画。

连续鼠标瞄准仍决定原有逻辑弹道；视觉帧以 8 方向和角度滞回切换。`TIP_UV` 按帧边界标记武器出手处。发射瞬间读取同一释放帧，烟雾留在世界空间；球/箭等在 0.09 秒内过渡到统一视觉高度。地面碰撞不依靠抬高后的贴图猜测，原有宽剑判定保留。近墙时从角色根到逻辑发射点再检查一次遮挡，防止弹体出生在墙另一侧。

完整持械方案优先保证握持和人体整体比例。游侠新图已修正正面和背向持弓；剑修左下、游侠右上方向使用整帧镜像校正左右朝向，不计为新增动作。若干斜向弓姿尚未精确沿射线，装填和三职业专用四技能帧仍需精修；代码不能替代缺失的原画。

## 动作检视室

主菜单入口或 F6 运行 `scenes/ActionInspector.tscn`。支持职业、离散方向、状态、速度、品质、技能等级，播放/暂停、单步、时间轴、出手标记与特效预览。青点是根位置，红点是视觉出手处。完整帧路线没有可以展示的真实骨骼关节，不画虚假的骨架。

右边是 2.0 持械立绘，左边是当前实用图集。预览仅改变表现，不生成装备、不扣天赋点、不改存档。等级改变预览的体量，不是假装进行完整伤害模拟。真实技能伤害验证见集成测试。

## 特效与声音

`weapon_art_v6.gd` 提供六件独立武器主体：普通剑、连发火枪、弓、巨剑、大箭、普通箭。战斗人物的武器已绘入人物帧，独立资源用于弹体、技能和拆件样板。没有给完整人物再叠画第二把手持武器。

`material_fx.gd` 使用 Kenney 火焰、烟雾、光斑、爆炸序列。粒子只处理位置/速度/寿命/旋转/颜色，不结算伤害。普通枪焰短促收缩，烟雾缓慢上升扩散；爆炸有主体、短亮核和后续烟团。低中高分别限制 24/48/80 个材质片；另有原有有界线粒子作补充。密集连锁爆炸不重复生成整批装饰碎屑。

大招继续由 `ultimate_controller.gd` 的原有有限时序结算。普通剑与巨剑、普通箭与巨箭选择不同图片；附加剑影和气浪没有额外伤害。高射速不等待长动画播放完成。

声音使用 CC0 金属、木材、爆破、摩擦等声音，与原有低音/魔法共鸣层组合。它们是游戏声音分层，不冒称真实古枪的实录。普攻和命中至少 3 个源变化，视觉随机和音频随机都与战斗 RNG 分离。Combat/UI/Ambience/Music 总线已建立；当前实际有战斗/UI声音，尚未加入完整音乐和环境声景。高优先级声音有专用混音声道，Master 限幅，普攻枪声尾音短渐出。暂停/菜单切换停止战斗尾音，退出释放声道。

音频程序检查提供源峰值、RMS、时长；保留 `v6-audio-source-review.wav` 供人工试听。本环境不能完成主观听音评审，不能声称已经通过专业混音验收。

## 噜噜与环境

复用 `czy666chen/lulu` 的 MIT 图集作待机/跑步与造型参考，保留作者许可。该仓库是桌宠动画资源，不是角色网格。新增 `art/v6/lulu-battle.png` 是内置 imagegen 生成的 6 列 × 4 行、24 帧专用动作图：鼓腮吹泡泡、抬手拍水、坐下泡澡、开心跳跃与挥手离开。预警期播放准备帧，原定攻击时刻切到释放帧；不增加伤害、不缩短预警。泡澡继续提供可攻击的空档，半血跳跃，战败友好挥手转身淡出。原始 PNG 的透明通道保留，背景 RGB 中的底色不参与绘制。初次生成曾受额度限制，恢复后重试成功。受击暂用闪亮反馈，尚无专用受击序列。

温泉水面 shader 提供局部明暗、水纹和轻微流动，浅水仍可通行；减少动态效果可关闭扰动。主线六章沿用原有主题贴图，以接近原始纹理尺度铺设，掩体加顶面和厚度。没有修改房间图、出口、掩体判定和导航网格。顶部小地图与战斗区不重叠。

## 后续必须补做的美术

1. 继续精修游侠斜向瞄准姿势，校正每张原画的弓弦与发射方向；手工复核所有释放点。
2. 将当前共享释放帧补成独立装填、搭箭、剑指、大招阶段、连携和收势序列，增加移动中腿部步态的中间帧。
3. 继续校正噜噜桌宠待机与新战斗图的大小/光照衔接，补画专用受击帧及更多过渡帧。
4. 增加可信的局部照明、法线和热扰动，先做性能预算再接入。
5. 人工试听并调整枪声、弓弦与剑鸣；本版没有完整环境音乐系统。

## 资源与复现

第三方来源、许可证、实际本地路径见 `sources-v6/downloads.json`，完整许可同目录。新增英雄/武器由内置 imagegen 生成，提示词和批次见 `generation-prompts.json` 与 `generated-assets.json`。没有使用外部 3D 模型，因此无 FBX/Blend 绑定源。

`tests/regression_v6.gd` 检查预览不改档、完整帧资源、出手高度、动画不重复发弹、随机源隔离、暂停、C 状态、贴墙发射、材质清理和声音通道；旧版测试复测存档、强化、天赋、地图、技能伤害、掉落和噜噜流程。`capture_v6`、`movie_v6` 是训练靶表现测试；`lulu_combat_v6` 使用正常 Lv.1 属性自动操作。录像不是手工试玩，也不以固定录像帧率充当性能数据。
