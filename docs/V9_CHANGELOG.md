# 0.9.0「形神合一」首批更新

本批集中修复三名主角普通攻击时人物、双手和武器缺少真实动作阶段的问题。旧实现保留一张完整持械立绘，再通过水平带网格轻微形变模拟六个阶段；轮廓变化小，也难以表达肩托、拉弓和斩击重心。

## 已完成

- 剑修、火枪手、游侠各增加一张 1536×1024 透明动作图集。
- 每张图集包含右、下、左、上四个朝向，每个朝向包含蓄势、压缩、释放、延展、回弹、收势六个完整角色与武器帧。
- 八方向输入映射到最近的绘制朝向，弹体、伤害和技能判定仍使用原有精确瞄准向量。
- 武器/弹道挂点随职业和动作阶段变化，避免特效从脚底或人物中心生成。
- 图集进行透明杂点清理、相邻单元隔离和统一脚底线处理。
- 普攻图集采用统一 0.50 显示比例。待机、普攻和回到待机使用同一节点缩放，人物身高不再在攻击瞬间跳变。
- 保留旧集成立绘渲染作为可关闭的回退路径，存档、数值、伤害和输入逻辑未改动。

## 素材说明

动作图集以工程现有 V6 集成立绘为角色视觉基准，通过 AI 辅助生成，再在本地完成透明单元清理、脚底对齐、Godot 接入、挂点调整和实际渲染检查。它们不是从其他游戏提取的资源，也不标注为人工逐帧手绘。更完整说明见 `art/v9/README.md`。

## 当前边界

这一批只替换普通攻击。待机/行走、闪避、受击、装填和四个主动技能仍主要使用 V8 的集成立绘与程序补间。四个绘制方向覆盖八方向输入，因此斜向攻击使用最近朝向；后续批次可继续补充斜向帧和职业代表技能帧。
