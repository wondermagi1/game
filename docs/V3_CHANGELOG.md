## 问题定位与修复

| 问题 | 原因 | 本次处理 |
| --- | --- | --- |
| 装备不能强化 | 新档 0 材料，按钮禁用没有解释；没有怪物材料来源 | 首次 3 材料，材料掉落，当前/下级预览、费用与不足原因；连续重复回调被拦截，保存失败回滚 |
| 快捷键不能指定实际按键 | 只有道具分配下拉框，InputMap 固定 1/2/3 | 独立键位服务，物理按键录入，冲突交换、取消、恢复默认、设置持久化、HUD 动态显示 |
| 天赋升级跳到顶部 | 每次重建 ScrollContainer，丢失滚动位置 | 保存页面/角色对应的滚动状态，布局后恢复焦点与位置；装备、商店、成就同样受益 |
| 火枪组合难触发 | 只有一发强化弹、火药区域短；on_hit 在目标死亡时提前返回 | 火药标记/区域 6 秒，F 至少 3 发强化弹；击杀位置仍引爆，强化子弹发光并显示剩余发数 |

| 存档解锁新章失败 | JSON 数字变成 float，Array.has(int) 不能可靠识别旧记录 | 加载时统一章节、技能等级为整数；保留 UID、已花点数、穿戴和材料 |

## 新增内容

六章主线、三种新普通怪（护盾祭司/裂生虫/星蚀术士）、两位新章节首领。第五章横向熔炉火带有安全缺口；第六章使用可逃离的延迟星印。最多 32 个敌人，增援按剩余槽位进入，章节难度不随玩家装备变化。

无尽深渊包含逐层奖励、五层整备和临时技能、十层轮换首领、三角色独立历史记录、检查点保存退出。前四章波次结构保持 2/3/5/7 回合，每回合至多三波。

图鉴扩为 Buff、装备、套装、技能、道具/材料、怪物/首领、章节/玩法、成就/秘闻八类。新增收藏、发现进度和 NEW 过滤；隐藏效果不会通过搜索泄露。浏览不授予任何物品。

成就、技能解锁/升级、套装激活、传奇掉落、Buff 进阶使用非阻塞通知队列；成就金币仍需主动领取，避免弹窗重复授予。

角色上限 60、技能上限 10、装备上限仍为 +10。等级 31 后采用平滑经验曲线；没有改旧角色已花天赋点。深渊 Buff 采用无限层数、四个进阶节点和输出转换，不通过制造无限实体实现成长。

## 美术与声音

保留三位英雄的原始角色图集。新增敌人用不同轮廓、法杖、附肢、护盾环、受击闪烁与死亡碎片区分。技能 5/8/10 级逐步增加外环、放射拖尾和觉醒法阵；危险预警绘制层高于玩家特效，降低特效密度不会隐藏危险。

合成音新增火枪低频爆破、剑气和弓箭组合提示以及成就提示；主音量/音效音量独立。采用有限音轨池与重复音效节流。当前尚非最终音频制作。

详细验证见根目录 TEST_REPORT.md。真实玩家档未用于自动测试；升级前项目备份位于工作目录的 work/threefold-v021-before-v3。
