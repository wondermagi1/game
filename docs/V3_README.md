# 三途试炼 · 第三版「深渊回响」0.3.0

三角色俯视角动作射击肉鸽的第三版可玩工程。已接入六章主线、无尽深渊、装备强化修复、自定义键位、八类图鉴、成就动画、技能与 Buff 进阶。角色延续第二版 2D 贴图，新敌人和战斗特效采用程序绘制。

## 启动

双击 `Play.cmd` 开始游戏；双击 `OpenEditor.cmd` 在 Godot 查看工程。也可在 Godot 4.7.2 导入本目录的 `project.godot`，按 F5。工程已设置 `scenes/Main.tscn` 为主场景。

如果屏幕上还开着旧版游戏，请先从旧窗口正常退出，再启动本版。已运行的进程不会自动加载脚本更新。同一存档不要同时开两个游戏窗口。

启动脚本使用本机 Godot 路径；换电脑时在 Godot 里导入工程，或将 `GODOT_PATH` 设为引擎 exe 的完整路径。工程包包含源码和资源，没有独立游戏 exe。

## 优先体验这些修复

1. **装备与强化**：新档及旧档升级首次获得 3 份材料。选择装备可查看当前/下级属性、金币与材料的持有/需求。强化必定成功，上限 +10；精英和首领固定给材料，多余装备可分解。金币不足或材料不足会明确说明。
2. **设置 → 自定义键盘按键**：点击动作后按新键；Esc 取消，冲突可确认交换。道具槽默认 1/2/3，可改为 Z/X/V 等；在装备页或整备页的“配置道具快捷栏”选择每槽药水。HUD 随键位更新。
3. **技能与天赋**：滚到列表底部升级，位置保持；角色最高 60 级，技能最高 10 级。普通技能仍于角色 1/5/10/15 级解锁，天赋点有限，不能全点满。
4. **火枪组合**：E 命中后留下 6 秒火药标记和地面区域；F 装填给接下来至少 3 发强化弹，命中即可引爆。普通换弹首发也可引爆；击杀目标仍会爆炸。Q 标记后普攻或 C 也能触发连爆。
5. **图鉴**：八个大类，左侧列表、右侧详情，可搜索、按角色/品质/发现状态筛选和收藏。NEW 只在打开已发现条目的详情后清除。
6. **新旅途**：完成第四章解锁熔炉回廊，再进入星蚀王座；完成第六章解锁无尽深渊。旧档已通第四章直接解锁第五章，无需重开。

## 默认操作

| 操作 | 默认输入 |
| --- | --- |
| 移动 / 瞄准 | WASD / 鼠标 |
| 普攻 | 按住左键 |
| 闪避 | Space |
| 四个技能 | E / Q / F / C |
| 火枪换弹 | R |
| 三个道具槽 | 1 / 2 / 3；可在设置里改键 |
| 暂停 / 属性 | Esc / Tab |

除左键、Esc 与 Tab 保留外，移动、闪避、换弹、技能和道具键均可重绑。按键录入时不执行战斗动作。窗口失焦会暂停。

## 深渊与保存

深渊每层一波战斗，结束三选一；第 5 层的倍数有精英与整备，第 10 层的倍数由首领战替代普通战。每五层随机提升一个技能的本局等级。Buff 无玩法层数上限，5/10/20/40 层触发真实进阶，数量和概率的超额收益转为攻击。

**只在五层整备点选择“保存深渊并退出”才能续玩。** 普通退出或战斗中结束挑战会保留永久收益，结束当前构筑。续玩恢复楼层、生命、Buff、临时技能、随机状态和已购买的商店库存；续玩前消耗检查点，强退不能重复领取同层奖励。深渊的不屈整次挑战只能复活一次。

永久档继续使用原来的 `user://profile_v2.json`，内部版本升级至 3；应用内部名称保持不变，因此旧存档目录不变。测试使用内存档或工程内隔离测试文件，不改真实玩家档。
