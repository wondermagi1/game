# 0.12 角色 3D 化适配

当前稳定二维版本已备份为 Git 分支 `codex/2d-backup-v0.11.1` 与标签 `v0.11.1-2d-backup`。3D 开发沿用现有二维玩法坐标、碰撞、伤害、技能、掉落和地图，只替换玩家的显示层。

## 第一阶段

- 剑修战斗显示改为透明 `SubViewport` 中的 3D 关节角色。
- 身体、四肢、头部和武器使用父子关节，剑固定在右手，不再以脚底原点单独旋转。
- 已接入待机、移动、普通攻击、技能、大招、闪避、受击、胜利和死亡状态。
- 角色转向采用连续插值，移动步态使用连续正弦周期。
- 游戏内“设置 → 画面与演出”可即时关闭剑修 3D 样板并回退原二维角色。
- 火枪手和游侠继续使用已验收的二维角色与旧版声音。

本阶段使用程序化白盒模型验证 2.5D 渲染、动作状态和性能边界。正式生产模型应从 Blender 以 GLB 导出，采用统一骨骼命名和动作库，再替换白盒网格。

## 正式模型接口

每名角色至少需要 `Idle`、八方向移动或自由转向移动、普通攻击连段、四个技能、闪避、受击、击倒、胜利和死亡动画。武器、枪口、箭矢与特效挂点必须绑定手部或武器骨骼。推荐保留以下挂点：

- `Socket_Weapon_R`
- `Socket_Weapon_L`
- `Socket_Muzzle`
- `Socket_VFX_Chest`
- `Socket_VFX_Foot_L`
- `Socket_VFX_Foot_R`

正式 GLB 模型进入 Godot 后由 `AnimationTree` 负责待机/移动混合、攻击状态切换和动作过渡；根运动关闭，位移继续由 `CharacterBody2D` 控制。

## 对标原则

《鸣潮》2.7“悲鸣行动：索拉战士”公开规则强调特殊战术视角、波次生存、局内强化角色与武器，以及局外天赋解锁。本项目借鉴这些玩法组织原则与清晰的俯视战斗可读性，不复制其角色、模型、贴图、声音、界面或剧情资产。
