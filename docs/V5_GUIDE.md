# 第五版实现说明

## 水豚噜噜 · 温泉奇遇

主菜单或章节选择页进入；可选择任意角色。地图独立于主线，由安全入口和温泉首领房两间房组成。安全入口可整备、保存与继续；胜利后可直接再次挑战。已保存其他挑战时先继续或放弃，不覆盖检查点。

噜噜是一只圆润棕色水豚，头顶橘子、披青色毛巾、拿小木桶。使用新生成的透明贴图，非第三方游戏模型。温泉浅水可自由通过，玩家不会被地形卡住。

| 参数 / 行为 | 实现 |
|---|---|
| 生命 / 护甲 / 移速 | 1150 / 5 / 76 |
| 基础伤害 | 9 |
| 泡泡喷泉 | 扇形 5 颗、速度 205、射程 1100；半血后 7 颗 |
| 拍拍水 | 玩家位置半径 105，预警 1.5 秒，伤害 10.8；半血后左右各增一个半径 80 的水花，预警 1.8 秒 |
| 泡澡时间 | 2.5 秒攻击窗口，不回血、不无敌 |
| 出场演出 | 约 3.2 秒；暂停战斗、冷却与伤害，允许跳过，恢复镜头与输入 |
| 奖励 | 首领原有掉落 + 清房金币/经验/材料 + 当前职业史诗饰品一件 |
| 成就 | 首胜解锁「噜噜的好朋友」，成就页一次性领取 180 金币 |

饰品等级不超过当前角色等级且最高 Lv.5；这是适合新角色的入门奖励，不替代后期高等级装备。挑战可重复获得保证饰品。清房固定 390 金币、540 经验、8 材料；胜利结算额外 150 金币、350 经验，另有首领掉落。不会解锁或标记主线首通。全部奖励遵守既有自动保存规则，重复结算不会再次发奖。

它定位轻松的可选切磋。低等级自动驾驶约 13–19 秒的有效战斗，不是长线高难度首领；真人时长未测。没有恐怖血腥画面，胜利文案为噜噜回温泉休息。

## 美术与交互

角色 ID 0/1/2 分别为御剑剑修、火药火枪手、长弓游侠；贴图、按钮、武器、特效颜色共用 `presentation.gd` 映射。角色采用前后视图、左右翻转、衣摆分层、武器独立旋转；移动、施法、后坐力、闪避残影、受击闪光与退场均有表现。保留原碰撞半径与伤害规则。

八种可爱怪物贴图覆盖原有十四种逻辑敌人，精英和首领使用颜色/大小/标记区分；噜噜为第十五种独立敌人。并非每种逻辑变体都拥有独立模型。

装备有三职业 × 六部位 SVG 图标、灰/蓝/紫/金品质色和选中光泽。装备详情分基础、强化、词条、专属效果；穿戴比较读取真实属性服务，强化显示实际下一等级和金币/材料要求。最高强化 +10。保存失败回滚，按钮短暂防连点，成功提供数字/光泽/音效反馈。

天赋升级保留滚动位置。技能预览使用同一武器表现组件，不创建正式战斗角色，不消耗资源；它是示意展示，技能机制以文字和实际战斗为准。成就通知沿用有界队列，管理页面暂缓消耗，避免翻页时丢失通知。

地图固定在顶部 HUD 内逻辑矩形 `(1275,24,335,96)`，战斗区域从 y=160 开始，二者不相交。完整地图仍为 M 打开的独立界面。

Boss 出场采用立绘、镜头推进、字幕和音效的实时演出，支持跳过/失焦暂停/返回菜单安全清理。默认自动跳过已看首领；可在画面选项关闭。没有预渲染 3D CG 影片。

低/中/高特效密度为 0.3 / 0.65 / 1.0。减少动态效果会降低闪光、停止视差/摆动/震屏等。视觉粒子使用独立随机源、有界池及批量绘制，不参加伤害判定。原有危险预警与技能主体保留。未提供每个视觉参数的独立滑杆。

## 保留规则和后续边界

六章/深渊、永久装备/技能点经济、正常掉率、房间生成与战斗伤害遵循第四版，本版不会为了演出额外发放旧档补偿。应用内部名称与存档版本不变。噜噜为可选的新模式，旧档没有该成就也能正常载入。

尚未制作完整 3D 模型、八方向逐帧动画、全身装备换装、预渲染电影或所有技能的精确预览。现阶段目标是已接入玩法的统一 2D 可玩表现；后续可逐项替换资源。性能实测与测试边界见根目录 `TEST_REPORT.md`。
