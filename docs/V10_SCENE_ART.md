# V10 场景美术升级

本批将六章战斗房间从重复铺设的方形地砖升级为六套独立全屏场景：翠庭、熔木要塞、月辉符文馆、绯樱祭坛、黄铜机关殿和星陨观测台。场景采用统一的俯视 2.5D 透视和边缘高细节、中央低对比构图，确保角色、敌人、弹道、危险预警和掉落物保持清晰。

运行时保留原房间碰撞、路线、传送门、掩体和任务逻辑；底图只负责材质、建筑和空间层次。每章另有一套受性能上限约束的环境动效，包括落叶、火星、符文微光、花瓣、蒸汽和星尘。降低特效或开启减少动态效果后，环境动效会同步减弱。
