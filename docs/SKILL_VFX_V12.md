## 美术方向

东方玄幻与西方魔幻交织：剑修沿用玩家认可的青白衣持剑形象，以实体飞剑、青蓝剑气为主体；游侠使用实体箭矢、自然魔法与星光；火枪手使用铜质弹头、黄铜弹体、炼金纹理、火焰和烟雾。实体主体保持清晰，粒子作为辅助。圆环仍用于范围与危险提示，不把所有必要的判定信息一并删除。

角色外观与最近加入的背景音乐保持现状。剑修/游侠大招已有的实体巨剑、巨箭继续使用。此修改不新增角色建模，也不把 2D 工程切换成 3D 游戏。

## 资源与性能约束

- 资源位于 `art/v12`，原来源页面与许可证副本位于其 `sources` 目录。
- `manifest.json` 记录原始素材、PSD 图层、文件哈希；`sources/download-manifest.json` 记录下载包哈希。
- `tools/import_skill_vfx.py` 复制原 PNG，并将指定 PSD 原图层导出为 PNG；不进行 AI 生成或像素重绘。
- `tools/bake_ammo.gd` 从 CC0 模型生成带材质/灯光的透明弹药图片。黄铜底环与铜质弧面头是本项目附加网格；游戏运行时使用 2D 图片，不逐发创建 3D 视口。
- 图片、四边形与 UV 缓存复用。技能图形保留最多 64 个事件；箭雨按特效档使用 3 或 7 个视觉箭矢；材质粒子沿用 24/48/80 的分档上限。
- 原平色辅助粒子的发射量下调，避免贴图层增加后数量无约束膨胀。这些是实现上的预算，**当前未取得帧率/显存实测结果**。
