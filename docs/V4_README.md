# 三途试炼 · 第四版「星途远征」0.4.0

可玩的 Godot 4 工程：三角色、六章房间探索、技能连携、装备成长与无尽深渊。第四版已接入真实战斗和旧存档迁移，不需要重开永久档。

## 启动

双击 **Play.cmd** 直接玩；双击 **OpenEditor.cmd** 查看工程，或在 Godot 4.7.2 导入 `project.godot` 后按 F5。主场景是 `scenes/Main.tscn`。房间模板在 `scenes/rooms/`，可直接在编辑器查看和编辑碰撞体；主场景的菜单与角色在运行时生成，可在 Remote 场景树检查。

启动入口默认使用本机 D 盘 Godot；其他电脑请导入工程，或设置 `GODOT_PATH` 为引擎 exe。交付的是源码工程，不含独立导出的游戏 exe。原第三版 ZIP 和开发前备份保留。不要同时运行两个使用同一永久存档的游戏进程。

## 本版优先体验

1. 主菜单 → 技能与天赋：每级 2 点，Lv.5/10/15/20/25/30 各额外 2 点。25 级可以将一个技能升至 10 级，C 仍在角色 15 级解锁。旧档按累计应得减已消费补齐。
2. 选择角色 → 章节：从安全营地出发，走向发光出口。战斗门清房后开启，每个战斗房一次三选一，普通奖励增加 2 层，精英/秘密奖励 3 层（主线上限内）。
3. 靠近房间中央按 **G** 开奇遇；安全房间其他位置按 G 整备，可换装、强化、升级技能、买补给、保存探索。
4. **M** 查看地图，Esc 返回。主路通向首领；精英、宝箱、镜渊为自选支路。支路整备提供返回分叉点的捷径。
5. 剑修 Q 是宽判定巨剑；C 为聚剑、落阵、巨剑终结。游侠 E 是大型贯日箭，C 为群星逐猎。火枪 C 有重火力持续和终结爆破。
6. 第五、六章首领必掉当前角色史诗或传奇，连续三次主掉落非传奇，下次主掉落必传奇；其他来源不影响这个计数。章节首通额外装备三选一。

## 操作

| 动作 | 默认按键 |
|---|---|
| 移动 / 瞄准 / 普攻 | WASD / 鼠标 / 按住左键 |
| 闪避 / 换弹 | Space / R |
| 四技能 | E / Q / F / C |
| 道具槽 | 1 / 2 / 3 |
| 交互、安全整备 / 地图 | G / M |
| 暂停 / 属性 | Esc / Tab |

在设置中可修改键盘绑定，既有自定义按键保留。若旧档已占用 G 或 M，新动作会使用空闲备用键，以 HUD 显示为准。道具槽物品与物理键位分别配置。

## 保存与继续

永久档仍是 `user://profile_v2.json`，内部版本 4，应用内部名称保持不变。永久金币、等级、装备自动保存。

主线只有在安全房间整备里选择“保存探索并退出”，才保留本局地图、Buff、生命、技能冷却、奇遇选择、破坏物、已售商品及随机状态。继续时先消耗检查点，之后可在安全房间再次保存。普通退出或死亡结束当前探索，不恢复战斗现场。

深渊保留每 5 层整备、每 10 层首领、无限 Buff 和临时技能成长；五层整备可保存续玩。旧第三版深渊检查点仍兼容。探索档与深渊档互斥，先继续或明确放弃再开新局。
