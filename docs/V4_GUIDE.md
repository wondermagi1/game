清房固定金币 `130+65*章`、经验 `160+110*章`、材料 `3+章`，精英/首领/秘密翻倍。探索基础经验 `100+80*章`。通关金币 `240+120*章`、经验 `400+220*章`。首通装备三选一使少怪仍有确定进步。

## 技能与伤害归属

全技能以实际 `skill_details.gd` 提供当前/下级说明，菜单含可用点数、下级门槛、费用和不能购买的原因。升级滚动位置保持。C有独立阶段状态机，只创建有限视觉剑影，逻辑伤害次数固定。

- 剑修Q：220像素主剑，Lv10为250；贯穿10，宽48，Lv3宽64。伤害 `(2.8+0.5*等级)*攻击`，8秒剑印；Lv5两把100%护卫剑；Lv8已有剑印目标额外80%范围伤害。
- 剑修C：0.35秒聚剑，约3秒落阵，终结。Lv1为250% + 8×100% + 650% = 1700%；Lv10为400% + 12×160% + 1000% = 3320%基础预算。Lv3扩大并跟随有效目标；Lv5终结交叉斩形态；Lv8终结剑变大；Lv10另有3次60%觉醒余阵。群体每个目标都能承受范围打击；组合收益另算。
- 火枪C：起手，4–5.35秒持续压制有效目标，终结爆破。持续最多 `24+2*等级` 发，每发 `(65+3.5*等级)%`；终结 `(500+35*等级)%`。Lv5每4发额外半伤害护卫弹，穿透增至3；Lv10余烬3次60%。无有效目标不向空气射击。
- 游侠E：230像素巨箭，宽48，贯穿12，`(300+65*等级)%`；猎印星爆240%。
- 游侠C群星逐猎：起手猎印，4–5.35秒优先追猎，终结星坠；持续最多 `10+等级` 发，每发 `(85+4.5*等级)%`；终结 `(500+35*等级)%`。移动+20%；Lv5护卫箭、穿透3，Lv10三次60%余阵。

目标选择优先存活猎印/剑印目标、首领和精英；目标死亡则转移，无目标时使用最后有效落点。3职业声音区分起手、持续与终结。低特效保留完整武器与危险预警，只减少装饰。普通子弹、巨剑、贯穿箭均受实体掩体阻挡；落剑、箭雨与爆炸属于区域法术，可越过掩体，但只影响当前激活房间。

## 房间、事件和秘密

房间图为受约束主路与可选支路，地图随机与视觉随机分开。每个房间有稳定ID、网格坐标（世界步长2200×1400）、模板、邻接门和奖励标志。逻辑显示仍1920×1080；镜头、出生、落点、安全位置和掉落用当前房间世界坐标。只实例化当前房间，离开清理弹体、范围效果与敌人。

第一章4房，第二章6房，第三章9房（包含必定存在的镜渊支路），第四至六章9–10房。主路明确，可选支路不阻塞首领。7个可编辑模板：开阔、柱阵、双通道、中央障碍、环形、精英、首领。木箱可破坏并保存破坏状态。敌人使用避障寻路与实体碰撞。六章装饰分别使用庭院植被、木架篝火、石柱符文、祭坛、机械熔炉、星图；仍是程序美术，不是最终环境资产。

普通遭遇通常6–9只、1波；精英每波7只、2波；首领独立遭遇，召唤数量限制。常规已取消计时无限增援。护盾祭司护盾降至目标最大生命10%，首领上限45，每8秒一次。

六类事件全部可进入主流程：行商（道具/史诗/材料）、祭坛（本局攻击/冷却/生命）、宝箱（装备+金币+材料）、治疗泉、工坊（武器强化或材料）、旅人（临时C等级/装备/经验）。效果及成本由事件界面明示，每个房间只能选一次；本局增益显示在属性列表，临时技能另标在升级页。可选精英房等价主动选择短试炼，清完可走捷径返回分叉。

主路r2北墙的三道微光是秘密线索：靠近并交互三次，第三章固定、后期80%地图含镜渊支路。进房后在封印处主动交互才挑战镜渊守望者。旧隐藏护符与成就ID保持。

小地图仅显示访问房及可见邻接房，秘密未开启不显示；M打开大图。清房后不重复刷怪或发奖，事件与商店不因回访刷新。

深渊复用模板循环，5层整备、10层首领及无限Buff保持；前期独立层数生命系数改为 `0.45+0.045F+0.0025F^1.7`，伤害为 `0.6+0.022F+0.0004F^1.5`，不读取玩家装备追涨。深渊的常规增援机制保留；主线房间事件不混入深渊检查点。

## 存档迁移

仍使用原应用内部名称和profile_v2.json，校验和/临时文件/备份机制保持。version升4，补充legend_misses和exploration，不替换装备UID、角色等级、已花点数、技能等级、已获得护符。重复加载不重复给点数；重置返回新累计应得总量。

探索检查点含图生成版本1、种子、run_id、当前/入口房、访问/清理/领取状态、邻接门、符纹、事件选择、木箱、商店库存、两个随机状态、角色生命、Buff、临时技能、道具与技能冷却、一次复活标志和本局统计。续玩先将检查点清空并保存成功，再重建房间。保存失败保留当前局。未提供任意战斗现场恢复。

旧自定义按键优先，新G/M若冲突自动找空闲键。原深渊version1检查点保持可读。未来版永久档仍只读保护。
