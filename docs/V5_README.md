# 三途试炼 · 第五版「绮光铸影」0.5.0

三角色俯视角动作肉鸽的可玩 Godot 工程。保留六章房间探索、装备/强化/天赋、组合技、图鉴、成就和无尽深渊；本版升级角色与可爱怪物美术、UI、装备反馈和技能表现，新增独立的水豚 Boss 挑战「噜噜温泉」。

## 直接体验

双击 **Play.cmd**；编辑工程用 **OpenEditor.cmd**，或在 Godot 4.7.2 导入 `project.godot` 后按 F5。主场景 `scenes/Main.tscn`。主菜单与战斗由脚本生成，运行后可在 Remote 场景树查看。交付的是源码工程，不是独立游戏 EXE。

启动脚本默认使用本机 D 盘 Godot；其他电脑请设置 `GODOT_PATH` 为引擎 EXE 或直接导入工程。首次启动需要导入图片。

**噜噜关入口：主菜单右下角「奇遇 · 噜噜温泉」→ 选择角色 → 向右穿过营地出口。** 章节选择页也有入口。三个角色都可挑战，无需先通关。它是轻松的可选切磋，不改变主线章节解锁。

## 本版变化

- 「御剑 / 火药 / 长弓」分别对应剑修、火枪手、游侠，菜单卡片与实际选择一致。新角色前后贴图、独立武器、动作摆动、命中与闪避反馈。
- 怪物改为可爱幻想生物；噜噜是戴橘子、披毛巾、拿木桶的水豚。泡泡喷泉、拍水预警、泡澡休息三种行为，半血后增加泡泡与水花。
- 主菜单绘制背景、统一面板与交互状态；十八个职业装备部位图标、四品质边框与光泽，强化前后数值和资源清晰展示，成功时动画与音效反馈。
- 普攻、大招和组合技增加武器贴图、光线与粒子；技能页可预览表现。Boss 有可跳过的实时出场演出。
- **小地图位于顶部 HUD 的专用区域，战斗区域从其下方开始。** M 仍可单独打开完整探索地图。
- 设置增加低/中/高特效、减少动态效果、菜单视差、已看 Boss 演出自动跳过。自定义按键会反映到技能提示。

## 操作

| 动作 | 默认按键 |
|---|---|
| 移动 / 瞄准 / 普攻 | WASD / 鼠标 / 按住左键 |
| 闪避 / 换弹 | Space / R |
| 四技能 | E / Q / F / C |
| 道具槽 | 1 / 2 / 3 |
| 交互、安全整备 / 地图 | G / M |
| 暂停 / 属性 | Esc / Tab |
| 跳过 Boss 演出 | Space / Enter / Esc / 鼠标点击 |

可在设置更改物理键位；旧档自定义绑定保留，以实际 HUD 为准。道具槽内容与键位分别配置。

## 保存与继续

继续使用 `user://profile_v2.json`，内部版本仍为 4；应用内部名称保持不变，因此不需要重开永久档。第五版不重新发放第四版技能点补偿。金币、经验、装备等按原规则保存。避免同时运行两个写入同一永久档的游戏进程。

安全房间按 G 整备，可选择“保存探索并退出”；噜噜入口营地也支持。保存的探索与深渊挑战互斥，先继续或放弃旧挑战才能开始新局。普通退出、死亡不恢复战斗现场。深渊仍每五层可保存。详见第四版玩法文档。

当前采用 **2D 前后贴图分层动画**，不是 3D 模型或完整八方向骨骼动画。Boss 是引擎内实时演出，音效为合成音；技能预览展示美术方向，不模拟每个技能的全部判定。装备外观体现职业武器和品质，没有六部件换装模型。

高密度压力场景的高特效约 53–57 FPS；拥挤深渊建议低特效。真人长期手感、更多硬件及最终商业美术仍需后续验证。V1–V4 报告是历史记录，本版测试以本次报告为准。
